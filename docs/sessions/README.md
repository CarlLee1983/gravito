# Active Development Sessions

This directory is reserved for temporary notes, meeting logs, and active improvement plans for the current development cycle.

## Lifecycle
- **Active Phase**: Work-in-progress plans and logs stay here.
- **Completion**: Once a session or phase is finished, records are moved to `docs/archive/` and future tasks are merged into `docs/internal/PENDING_IMPROVEMENTS.md`.
