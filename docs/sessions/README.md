# 📔 Gravito Session 紀錄指南

本目錄 `docs/sessions/` 用於記錄 Gravito 開發過程中的關鍵階段、改善計劃以及任務完成報告。

## 檔案命名規範

- **改善計劃**: `IMPROVEMENT_PLAN_YYYY_QN.md` (例如: `IMPROVEMENT_PLAN_2026_Q1.md`)
- **任務報告**: `[TASK_NAME]_REPORT.md` (例如: `DOC_VALIDATION_CI_REPORT.md`)
- **會議/會話紀錄**: `SESSION_YYYY_MM_DD.md`

## 當前關鍵文檔

1. [2026 Q1 改善計劃（已完成）](./IMPROVEMENT_PLAN_2026_Q1_COMPLETED.md): 記錄了從 Phase 19 到規格文件標準化的所有已完成項目。
2. [文檔驗證 CI 報告](./DOC_VALIDATION_CI_REPORT.md): 詳細說明了自動化文件品質檢查系統的實作。
3. [未來路線圖：衛星 DX 與標準化](./FUTURE_ROADMAP_SATELLITE_DX.md): 定義了規格制定後的具體執行任務。
4. [會話紀錄：2026-02-03 規格改革](./SESSION_2026_02_03_SPEC_REFORM.md): 記錄本次規格標準化的決策脈絡與產出。

## 維護建議

- 每個主要階段結束後，應更新對應的 `IMPROVEMENT_PLAN`。
- 過時的臨時任務檔案（如 `NEXT_SESSION_TASK.md`）在完成後應併入改善計劃或予以刪除。
