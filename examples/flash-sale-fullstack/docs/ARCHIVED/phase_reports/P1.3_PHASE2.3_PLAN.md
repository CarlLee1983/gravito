## 📊 性能指標定義

### 延遲百分位數（Latency Percentiles）

```
P50 (中位數)：50% 的請求延遲 <= 此值
P95：95% 的請求延遲 <= 此值
P99：99% 的請求延遲 <= 此值
Max：最大延遲（峰值）
```

### 吞吐量 (Throughput)

```
ops/sec：每秒完成的操作數
提交吞吐量：EventAggregator.submit() 的 QPS
實際吞吐量：包括隊列處理的完整管道 QPS
```

### 隊列深度管理 (Queue Depth)

```
平均深度：整個測試期間的平均隊列深度
峰值深度：測試期間的最大隊列深度
穩定性：深度波動百分比
```

### 記憶體效率 (Memory Efficiency)

```
初始記憶體：測試開始時的堆使用量
峰值記憶體：測試期間的最大堆使用量
增長率：(峰值 - 初始) / 初始
洩漏檢查：最終記憶體是否接近初始值
```
