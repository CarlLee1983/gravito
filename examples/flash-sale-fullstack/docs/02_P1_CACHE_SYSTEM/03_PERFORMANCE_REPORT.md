## C. 告警規則配置

### 推薦的監控告警

| 指標 | 告警閾值 | 嚴重級別 | 建議行動 |
|------|---------|---------|---------|
| 吞吐量 | < 500 ops/sec | ⚠️ 警告 | 檢查系統負載 |
| 平均延遲 | > 5ms | ⚠️ 警告 | 監控隊列堆積 |
| P95 延遲 | > 20ms | ⚠️ 警告 | 檢查 GC 暫停 |
| P99 延遲 | > 50ms | 🔴 嚴重 | 立即調查 |
| 隊列深度 | > 9000 | 🔴 嚴重 | 擴容或流量控制 |
| 錯誤率 | > 1% | 🔴 嚴重 | 觸發快速響應 |
| 記憶體 | > 500MB | ⚠️ 警告 | 檢查內存洩漏 |

### 告警規則示例

```yaml
# Prometheus 告警規則
groups:
  - name: flash_sale_alerts
    interval: 30s
    rules:
      - alert: FlashSaleLowThroughput
        expr: flash_sale_throughput < 500
        for: 2m
        annotations:
          summary: "秒殺系統吞吐量過低"

      - alert: FlashSaleHighLatency
        expr: flash_sale_avg_latency > 5
        for: 1m
        annotations:
          summary: "秒殺系統延遲升高"

      - alert: FlashSaleQueueFull
        expr: flash_sale_queue_depth > 9000
        for: 30s
        annotations:
          summary: "秒殺系統隊列接近滿"
```
