### 1️⃣ CacheEvent 對象池實現 (8h)

#### 目標
- 消除高頻事件對象的 GC 壓力
- 複用 CacheEvent 對象，減少內存分配
- 預期改進：15-20%

#### 實施步驟

**1.1 對象池管理器設計 (2h)**

```typescript
// src/cache/events/ObjectPool.ts
class CacheEventPool {
  private pool: CacheEvent[] = []
  private maxSize: number
  private createFn: () => CacheEvent
  private resetFn: (event: CacheEvent) => void

  // 核心方法
  acquire(): CacheEvent
  release(event: CacheEvent): void
  resize(newSize: number): void
  getStats(): PoolStats
}

interface PoolStats {
  poolSize: number
  available: number
  reused: number
  created: number
  hitRate: number
}
```

**1.2 集成到 EventAggregator (3h)**

- 修改 `EventAggregator.submit()` 使用對象池
- 在 `processEvents()` 中歸還對象
- 配置最優池大小（基於負載測試）

**1.3 測試驗證 (3h)**
