```

• LRU/LFU 驅逐策略
• 異步和同步複製
• 命中率 > 95%
```

```
監控範圍：15+ 指標

• 快取命中率

• Critical：5xx 錯誤 > 1%，P99 > 300ms → PagerDuty
• Warning：0.5-1% 錯誤 → Slack
• Info：監控記錄
```
