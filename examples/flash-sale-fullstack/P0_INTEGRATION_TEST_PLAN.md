## 🧪 詳細測試計劃

### 第 1 天：功能驗證

#### 上午（2-3 小時）

**任務**：基礎功能驗證

```bash
# 1. 啟動完整系統
docker-compose up -d

# 2. 驗證所有服務健康
echo "=== 服務健康檢查 ==="
for service in postgres redis jaeger prometheus alertmanager grafana; do
  echo "檢查 $service..."
  curl -s http://localhost:port/health
done

# 3. 啟動應用
bun run dev

# 4. 驗證應用啟動日誌
tail -50 /tmp/app.log | grep -E "PoolManager|Tracing|started"

# 5. 生成測試流量
curl -X POST http://localhost:3000/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "test-user-1",
    "productId": "product-0",
    "quantity": 1
  }'
```

**驗收標準**：
- ✅ 所有服務正常運行
- ✅ 應用成功啟動
- ✅ API 可正常訪問
- ✅ 沒有錯誤日誌

#### 下午（3-4 小時）

**任務**：追蹤系統驗證

```bash

# 3. 在 Jaeger UI 中查詢追蹤
# http://localhost:16686

# 4. 檢查追蹤採樣率
curl -s 'http://localhost:16686/api/traces?service=flash-sale-service' | jq '.data | length'
```

**驗收標準**：
- ✅ Jaeger 收到追蹤
- ✅ 追蹤覆蓋 100%
