## 🚀 Bootstrap Lifecycle

1. **Configure** - Load configuration, register Orbits
2. **Boot Core** - Initialize PlanetCore with PhotonAdapter
3. **Register Providers** - Database, Auth, Mail, Middleware, Route
4. **Bootstrap** - Boot all providers, initialize services

## 🏗️ Architecture Patterns

### MVC Pattern
- **Models**: Data representation with Atlas ORM
- **Views**: Vue 3 components via Inertia.js
- **Controllers**: Request handling and response

### Service Provider Pattern
All infrastructure concerns are encapsulated in Service Providers.

### Service Layer
Complex business logic (registration, notifications) in dedicated services.

## 📚 Key Features

### Dynamic Custom Fields
Events can define custom registration fields (text, select, checkbox, etc.)

### Email Notifications
Using `@gravito/signal` for transactional emails.

### QR Code Check-in
Generate unique QR codes for registrations, scan to check in.
