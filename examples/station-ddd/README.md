# station-ddd (example)

Minimal DDD base for Gravito. Same layout as the cmg-station-ddd minimal base: entry, bootstrap, routes, health + sample API. Uses `workspace:*` so it runs from the monorepo.

- `bun run dev` – Start server (from repo root: `bun install` first)
- `bun run typecheck` – TypeScript check
- `bun test` – Run tests
