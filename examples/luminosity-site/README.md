# 🌌 Project Luminosity: Marketing Site

The official showcase website for **Gravito Luminosity** - The Enterprise Sitemap Engine.

## 🌟 What's New in Luminosity 2.0
- **Universal Framework Support**: Now scans Remix, SvelteKit, Fastify, and Astro routes automatically.
- **Rich Media SEO**: Complete support for Google Image and Video sitemap extensions.
- **Production Resilience**: Self-healing LSM engine with `lux repair` command.
- **Developer Experience**: New `lux inspect <url>` command for instant meta tag previews.

## 📡 Architecture
- **Framework**: Gravito Core + Orbit Ion (Inertia)
- **Frontend**: React + TailwindCSS + Framer Motion
- **Deployment**: Static Export (SSG) to GitHub Pages
- **CNAME**: `luminosity.gravito.dev`

## 🎨 Visual Identity
- **Theme**: "Constellation" (Deep Space Black + Radar Green/Amber)
- **Metaphor**: Scanning the infinite web.
