# Gravito E-Commerce MVC Example

**版本 1.1.0**

這是一個基於 **Gravito Framework** 打造的高效能電子商務 MVC 示範專案。展示了如何結合 **OrbitAtlas (ORM)**, **OrbitIon (Inertia.js)**, **OrbitSentinel (Auth)**, **OrbitPulsar (Sessions)** 以及 **OrbitPrism (Vite/Views)** 構建現代化的 Web 應用。

## 🗄️ 本地資料庫設置

### 使用 SQLite (預設)
應用程序預設使用 SQLite 記憶體模式 (`:memory:`)，無需任何設置。資料會在每次伺服器重啟時重置。

### 使用 PostgreSQL (Docker)
1. 啟動資料庫容器：
   ```bash
   docker-compose up -d
   ```
2. 建立並配置 `.env` 檔案：
   ```bash
   cp .env.example .env
   ```
3. 更新 `.env` 以使用 PostgreSQL：
   ```env
   DB_CONNECTION=postgres
   DB_PASSWORD=password
   ```
4. 重啟開發伺服器。

### 移除環境
若要停止並移除資料庫及其所有資料：
```bash
docker-compose down -v
```

## 🚀 快速開始

### 1. 安裝依賴
```bash
bun install
```

### 2. 啟動開發伺服器
```bash
bun run dev
```
伺服器將運行在：`http://localhost:3070`

## ✨ 主要功能 (v1.1.0)

- **完整購物體驗**: 商品瀏覽、搜尋、購物車管理與結帳流程。
- **客戶服務中心**: 完整的常見問題、運送政策、退換貨說明與聯絡我們頁面，具備互動式介面。
- **後台管理系統**: 商品、分類與訂單的後端管理 Dashboard。
- **安全身份驗證**: 用戶註冊、登入與安全的 Session 管理 (OrbitPulsar)。
- **精緻 UI/UX**: 響應式設計、深色模式支援 (Dark Mode)、細微動畫與骨架屏載入效果。

## 🛠️ 技術棧
- **Backend**: [Gravito Core](https://github.com/gravito-framework/gravito) (Bun Runtime)
- **ORM**: OrbitAtlas (SQLite)
- **Frontend**: Vue 3 + Inertia.js (OrbitIon)
- **Styling**: Vanilla CSS + UnoCSS (Tailwind compatible)
- **Session**: OrbitPulsar
- **Build Tool**: Vite

## 📂 專案結構
- `src/Http/Controllers`: 業務邏輯處理中心 (含商店、購物車、訂單、後台與頁面控制器)。
- `src/Models`: 數據模型與 Atlas ORM 定義。
- `src/client/pages`: Vue 頁面組件 (Inertia)，包含新增的 `Support/` 目錄。
- `config/`: 框架軌道 (Orbits) 與安全性設定。
- `database/`: 包含遷移 (Migrations) 與種子數據 (Seeders)。
