# Gravito E-Commerce MVC Example

這是一個基於 **Gravito Framework** 打造的高效能電子商務 MVC 示範專案。展示了如何結合 **OrbitAtlas (ORM)**, **OrbitIon (Inertia.js)**, **OrbitSentinel (Auth)** 以及 **OrbitPrism (Vite/Views)** 構建現代化的 Web 應用。

## 🚀 快速開始

### 1. 安裝依賴
```bash
bun install
```

### 2. 啟動開發伺服器
```bash
bun run dev
```
伺服器將運行在：`http://localhost:3070`

### 一般客戶 (Customer)

## 🛠️ 技術棧
- **Backend**: [Gravito Core](https://github.com/gravito-framework/gravito) (Bun Runtime)
- **ORM**: OrbitAtlas (SQLite)
- **Frontend**: Vue 3 + Inertia.js (OrbitIon)
- **Styling**: Vanilla CSS + UnoCSS (Tailwind compatible)
- **Build Tool**: Vite

## 📂 專案結構
- `src/Http/Controllers`: 業務邏輯處理中心。
- `src/Models`: 數據模型與 Atlas ORM 定義。
- `src/client/pages`: Vue 頁面組件 (Inertia)。
- `config/`: 框架軌道 (Orbits) 與安全性設定。
- `database/`: 包含遷移 (Migrations) 與種子數據 (Seeders)。

## 📸 圖片處理
本專案整合了 **Unsplash** 高品質 API 圖片，並使用自定義的 `GImage` 組件實作圖片懶加載 (Lazy Loading) 與骨架屏 (Skeleton) 載入效果。
