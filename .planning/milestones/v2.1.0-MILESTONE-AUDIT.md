## Design Decisions Worth Noting

1. **Browser barrel exception exclusion** — `index.browser.ts` intentionally omits exception exports. Browser consumers cannot `instanceof`-check `ModelNotFoundException`. This is likely correct (server-only concerns) but undocumented.

2. **observabilityProvider path asymmetry** — `ApplicationConfig` excludes `observabilityProvider` via `Pick<GravitoConfig, 'logger' | 'config'>`. This is architecturally consistent (Application = simplified API, PlanetCore = full control) but not covered in the DOC-06 orbit/register/use decision guide.
