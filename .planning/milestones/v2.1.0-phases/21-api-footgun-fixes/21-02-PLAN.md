**FIX-02: Replace string sentinel with direct ModelNotFoundException throw (lines 435-436, 473-479)**

Step A — In the `model()` method resolver (around line 435-436), change:
```typescript
if (!instance) {
  throw new Error('ModelNotFound') // Will be caught by 404 handler if we handle it
}
```
to:
```typescript
if (!instance) {
  throw new ModelNotFoundException(param, String(id))
}
```

Note: Use `id` (the resolver function argument), NOT `value` (which is an outer scope variable from the middleware). The resolver closure receives `id` as its parameter at line 426: `this.bind(param, async (id) => {`.

Step B — In the middleware catch block (around lines 473-479), simplify:
```typescript
// Before:
} catch (err: unknown) {
  const message = err instanceof Error ? err.message : undefined
  if (message === 'ModelNotFound') {
    throw new ModelNotFoundException(param, value)
  }
  throw err
}
```
```typescript
// After:
} catch (err: unknown) {
  throw err
}
```

The `message` local variable is removed entirely to satisfy TypeScript `noUnusedLocals`. The catch block now simply re-throws — ModelNotFoundException propagates directly from the resolver.
