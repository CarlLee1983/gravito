    Create `docs/migration/v2.0.0.md` with the following structure (per D-13):

    **1. Quick Start (3-5 lines)**
    - Most common upgrade path: update peerDependencies to new major ranges, replace bare `catch (e) { if (e.message === '...') }` with `catch (e) { if (e instanceof GravitoException && e.code === 'db.connection_failed') }`.

    **2. Breaking Changes**

    Organize by category:

    **2a. Error Handling (Phase 16)**
    - All Orbit errors now extend `GravitoException` with `.code`, `.status`, `.cause` fields
    - Before: `throw new Error('Database connection failed')` / `catch (e) { if (e.message.includes('connection')) }`
    - After: `throw new DatabaseException(503, 'db.connection_failed', { cause })` / `catch (e) { if (e instanceof DatabaseException && e.code === 'db.connection_failed') }`
    - `instanceof` checks work across ESM/CJS boundaries (Object.setPrototypeOf in all constructors)
    - Error hierarchy: `GravitoException` > `InfrastructureException` / `DomainException` > package-specific errors (DatabaseException, CacheException, AuthException, etc.)

    **2b. Resilience Primitives (Phase 17)**
    - New: `withRetry(fn, { idempotent: true, maxAttempts: 3 })` for retry with backoff
    - New: `withResilience(fn, policy)` for composing timeout + CB + retry
    - `CircuitOpenException` thrown when circuit breaker is open (replaces generic errors)
    - `RetryExhaustedException` thrown after all retries fail
    - Three duplicate CircuitBreaker implementations consolidated into `@gravito/resilience`

    **2c. Graceful Degradation (Phase 20)**
    - New: `OrbitDegradationManager` for typed fallback on circuit-open
    - Before: `try { await withResilience(fn, policy) } catch (e) { /* manual fallback */ }`
    - After: `const result = await mgr.execute('atlas', fn); if (result.degraded) { /* use result.value fallback */ }`
    - `DegradedResult<T>` with `.degraded`, `.source` ('live' | 'fallback'), `.value`
    - In `NODE_ENV=test`, DegradationManager throws instead of returning fallback (test safety)

    **2d. Health Monitoring (Phase 19)**
    - All I/O Orbit packages now register health checks with `@gravito/monitor` HealthRegistry
    - `/health` endpoint returns per-Orbit `healthy`/`degraded`/`unhealthy` status
    - Shutdown handlers registered with configurable deadline for atlas, plasma, signal, stream, beam

    **3. Per-Package Version Changes**

    Table with columns: Package | Old Version | New Version | What Changed

    Read the ACTUAL version from each package.json to populate the "New Version" column. For "Old Version", compute by subtracting 1 from the current major (e.g., if current is 3.0.0, old was 2.x.y).

    Include all 38 packages from the bump list.

    **4. Updating Your Code**

    Step-by-step instructions:
    1. Update peerDependencies in your package.json to new major ranges
    2. Replace `catch (e) { if (e.message === '...') }` with `catch (e) { if (e instanceof XxxException) }`
    3. Use `.code` field instead of `.message` for programmatic error handling
    4. (Optional) Use `OrbitDegradationManager` for circuit-open fallback instead of manual try/catch

    **5. FAQ**
    - "Do I need to change my Satellite code?" — Only if you were catching errors by `.message` string. `instanceof` checks for existing error classes still work.
    - "What about `atlas.transactionWithRetry`?" — It still works unchanged. Do NOT wrap it with external `withRetry` (quadratic retries).

    The guide should be ~200-300 lines. Use clear Markdown headings, code blocks with TypeScript syntax highlighting, and a version table.
