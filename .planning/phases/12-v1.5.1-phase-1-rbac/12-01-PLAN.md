  <action>
Identify high-impact optimization opportunities and implement 2–3 strategic enhancements.

1. **Analyze performance baseline from Task 1:**
   - Which operations are slowest? (identify top 3)
   - Are there any O(n) or O(n²) operations? (e.g., checking permission in loop)
   - Is there unnecessary repetition (e.g., loading same role multiple times)?

2. **Identify optimization candidates (document all, even if not implemented):**
   - **Permission Caching:** Cache checked permissions (userId + permissionKey) for N seconds
     * Estimated impact: 30–50% faster permission checks
     * Effort: 3–4 hours
     * Risk: Cache invalidation complexity

   - **Role Query Indexing:** Index role.name, permission.key in database
     * Estimated impact: 20–40% faster role lookups
     * Effort: 1–2 hours
     * Risk: Low (database-level change)

   - **Lazy-load permissions:** Don't load all permissions for a role unless needed
     * Estimated impact: 25–35% faster role resolution with many permissions
     * Effort: 2–3 hours
     * Risk: API contract might change (need lazy-loading support)

   - **Batch permission checks:** Support checking 10+ permissions in one operation
     * Estimated impact: 40–60% faster bulk checks
     * Effort: 2–3 hours
     * Risk: Moderate (new API surface)

   - **Remove N+1 queries:** Audit for cases where each role loads permissions separately
     * Estimated impact: 15–25% faster bulk operations
     * Effort: 2–4 hours
     * Risk: Moderate (query refactoring)
