## Task 2: Strategy Decision

### Decision Framework

**Option A: Keep as Core Dependency**
- Rationale: OpenAPI is important for API documentation/clients
- Action: Keep in package.json, maintain tests
- Cost: Adds dependency weight

**Option B: Remove Entirely**
- Rationale: Not essential, users can add if needed
- Action: Remove from package.json and imports
- Cost: Breaking change if users depend on it

**Option C: Move to Separate Adapter**
- Rationale: Optional OpenAPI generation can be separate
- Action: Create @gravito/photon-openapi adapter
- Cost: New package structure, migration needed

**Recommendation:** Depends on usage:
- If heavily used (multiple files, good tests) → Option A
- If minimal usage → Option C (move to adapter)
- If unused → Option B (remove)

### Decision Template
```markdown
## @hono/zod-openapi Strategy

**Current Usage:** [X references in Y files]

**Strategic Importance:** [high/medium/low]

**Rationale:** [decision reason]
**Migration Path:** [if changing: how users transition]
**Timeline:** [when to implement]
```
