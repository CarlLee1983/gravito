  <files>

  </read_first>
  <action>
    1. Create audit directory: `mkdir -p .planning/phases/06-full-audit-optional/audit/documentation`

    2. Generate TypeDoc JSON report for the three main packages:
       - Run: `npx typedoc --json .planning/phases/06-full-audit-optional/audit/documentation/typedoc-output.json packages/photon/src packages/core/src packages/signal/src 2>/dev/null || echo "TypeDoc completed with warnings"`

    3. Parse TypeDoc JSON to calculate JSDoc coverage:
       - For each package, identify top-level exported items (classes, functions, interfaces, types)
       - Count items with JSDoc comments (check for .comment.shortText or .comment.text)
       - Calculate coverage percentage: (documented / total) * 100
       - Flag items with no documentation

    4. Create coverage analysis script (bun) or use jq:
       ```bash
       # If TypeDoc json available:
       bun -e "
       const fs = require('fs');
       const data = JSON.parse(fs.readFileSync('.planning/phases/06-full-audit-optional/audit/documentation/typedoc-output.json', 'utf8'));
       const result = {};
       data.children?.forEach(child => {
         const total = child.children?.length || 0;
         const documented = child.children?.filter(c => c.comment?.shortText || c.comment?.text)?.length || 0;
         result[child.name] = {
           total_items: total,
           documented_items: documented,
           coverage_percent: total > 0 ? Math.round(documented / total * 100) : 100
         };
       });
       console.log(JSON.stringify(result, null, 2));
       " > .planning/phases/06-full-audit-optional/audit/documentation/jsdoc-coverage.json
       ```

    5. Manual spot-check for photon (most critical package):
       - Open packages/photon/src/index.ts
       - Verify top 10 exported items have JSDoc comments
       - Look for: @param, @returns, @example, @throws, @deprecated
       - Flag any missing documentation on public functions/classes

    6. Expected output schema for jsdoc-coverage.json:
       {
         "packages": {
           "photon": {
             "total_items": number,
             "documented_items": number,
             "coverage_percent": number,
             "undocumented_items": ["item1", "item2"],
             "status": "GREEN|YELLOW|RED"
           },
           "core": { ... },
           "signal": { ... }
         },
         "summary": {
           "total_coverage_percent": number,
           "packages_below_80_percent": [...]
         }
       }

    7. If TypeDoc fails, fall back to grep-based counting:
       - Count: `grep -c "^export" packages/photon/src/index.ts`
       - Count JSDoc: `grep -B3 "^export" packages/photon/src/index.ts | grep -c "^\s*\*"`
       - Coverage = JSDoc count / export count * 100

    8. Validate output: `bun -e "const j=JSON.parse(require('fs').readFileSync('.planning/phases/06-full-audit-optional/audit/documentation/jsdoc-coverage.json', 'utf8')); console.log('photon:', j.packages.photon.coverage_percent, '%')"`
  </action>
  <verify>
    <automated>
      # Verify jsdoc-coverage.json exists and has required fields
      test -f .planning/phases/06-full-audit-optional/audit/documentation/jsdoc-coverage.json && \

      echo "JSDoc coverage analysis complete"
    </automated>
