    3. Create a simple HTTP server to test (if not exists):
       - Use photon example or create `scripts/perf-server.ts` that starts a basic Hono server
       - Listen on port 3000
       - Implement GET / handler that returns 200 OK with minimal JSON response

    4. Run HTTP latency benchmark using autocannon:
       - Start the server in background: `node --expose-gc packages/photon/examples/http-server.js &`
       - Wait 2 seconds for server startup
       - Run: `npx autocannon -c 100 -d 30 --json http://localhost:3000 > .planning/phases/06-full-audit-optional/audit/performance/photon-latency.json`

    5. Measure container startup time:
       - Create `scripts/measure-startup.ts` that:
         * Imports createContainer from @gravito/core
         * Records process.hrtime() before createContainer()
         * Records process.hrtime() after createContainer()
         * Outputs timing in milliseconds
       - Run: `bun scripts/measure-startup.ts` 5 times and average
       - Store median of 5 runs in memory-profile.json

    6. Capture heap memory baseline:
       - Run server with: `node --expose-gc --inspect packages/photon/examples/http-server.js`
       - In separate terminal: `node --expose-gc scripts/perf-client.ts` (create client that sends 100 requests over 10s)
       - Manually connect Chrome DevTools (chrome://inspect), take heap snapshot before load, after load, post-GC
       - Or use Node.js heapdump programmatically: run server, send 1000 requests via autocannon, read process.memoryUsage()
       - Store baseline heap size (rss, heapUsed, heapTotal) in memory-profile.json

    7. Output JSON schema for photon-latency.json:
       {
         "requests": [
           {
             "path": "/",
             "latency": {
               "p50": number_ms,
               "p95": number_ms,
               "p99": number_ms
             },
             "throughput": { "average": number_req_per_sec }
           }
         ]
       }

    8. Output JSON schema for memory-profile.json:
       {
         "startup_time_ms": number,
         "rss_baseline_mb": number,
         "heap_used_mb": number,
         "heap_total_mb": number,
         "gc_time_ms": number
       }

    9. Verify both JSON files are valid and contain required fields using: `bun -e "console.log(JSON.parse(require('fs').readFileSync('.planning/phases/06-full-audit-optional/audit/performance/photon-latency.json', 'utf8')))"`
