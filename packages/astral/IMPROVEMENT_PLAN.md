## 現況分析

### 模組概述

`@gravito/astral` 是一個 Schema 驅動的 OpenAPI 生成器，採用「影子契約」(Shadow Contracts) 設計模式，將 API 文檔定義與業務邏輯分離。

**核心統計：**

| 項目 | 數值 | 備註 |
|------|------|------|
| 總代碼行數 | ~1500 行 | 含測試、範例與驗證專案 |
| 測試用例 | 37 個 | 單元測試 (覆蓋率 100%) |
| 驗證專案 | 1 個 | E2E 完整驗證 (examples/astral-verification) |
| 當前版本 | v1.0.0 | 已具備發布條件 |

### 架構組成

```
packages/astral/
├── src/                  # 核心源碼 (100% Coverage)
├── tests/                # 測試套件
├── docs/                 # API 與進階文檔
│   ├── API.md
│   └── ADVANCED.md
└── examples/             # 範例庫
    ├── basic-crud/
    ├── authentication/
    └── custom-errors/

examples/
└── astral-verification/  # v1.0 驗收專案 (Reference Implementation)
```
