## 現況分析

### 模組概述

`@gravito/astral` 是一個 Schema 驅動的 OpenAPI 生成器，採用「影子契約」(Shadow Contracts) 設計模式，將 API 文檔定義與業務邏輯分離。

**核心統計：**

| 項目 | 數值 | 備註 |
|------|------|------|
| 總代碼行數 | ~1000 行 | 含測試與範例 |
| 測試用例 | 37 個 | 覆蓋率 100% |
| 範例專案 | 3 個 | Basic, Auth, Errors |
| 當前版本 | 0.1.2 | |

### 架構組成

```
packages/astral/
├── src/                  # 核心源碼 (100% Coverage)
├── tests/                # 測試套件
├── docs/                 # API 與進階文檔
│   ├── API.md
│   └── ADVANCED.md
└── examples/             # 範例庫
    ├── basic-crud/
    ├── authentication/
    └── custom-errors/
```
