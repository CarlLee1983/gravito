# 風險評估與緩解措施

## 🔴 高風險項目

### 1. Proxy 優化（破壞性變更風險）

**風險：** 快取失效問題，動態 accessor 無法識別

**緩解措施：**
- 在開發模式下保持完整檢查
- 添加 `clearProxyCache()` 用於測試
- 全面的邊界情況測試套件
- 提供遷移指南

---

### 2. Relationship API 變更（破壞性變更）

**風險：** 從 thenable 改為方法調用是破壞性的

**緩解措施：**
- **延後到後續版本**（不在當前計劃中）
- 漸進式遷移：在 1-2 個版本中同時支援兩者
- 提供 codemod 工具
- 詳細文檔

---

## 🟡 中風險項目

### 3. DirtyTracker 淺層比較

**風險：** 深層嵌套變更無法偵測

**緩解措施：**
- 明確記錄限制
- 提供 `setDeepComparison(true)` 選項
- 添加邊界情況測試
- 記錄解決方法
- **建議：** 開發環境添加 mutation 警告

---

### 4. LRU 快取命中率

**風險：** 動態查詢降低快取效果

**緩解措施：**
- 使快取大小可配置
- 改進快取鍵生成
- 添加監控/指標
- 允許按查詢禁用

---

### 5. Grammar 快取架構變更（審視後新增）

**風險：** 從實例級改為靜態快取可能影響多租戶場景

**緩解措施：**
- 提供 `Grammar.setCacheScope('instance' | 'global')` 選項
- 預設使用全局快取（大多數情況更優）
- 添加快取隔離選項給多租戶應用

---

## 🟢 低風險項目

### 6. 類型改進
- 風險極小，僅編譯時
- 完整測試覆蓋率足夠

### 7. 錯誤訊息
- 僅為新增變更
- 無破壞性變更
