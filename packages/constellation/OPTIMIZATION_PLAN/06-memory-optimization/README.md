## 優化結果

主要的內存壓力已透過以下手段解決：

1. **XML 構建優化 (Phase 1)**: 使用 `Array.join` 替代大量字串拼接，減少臨時字串分配。
2. **流式存儲讀取 (Phase 4)**: 實施 `readStream` 並升級 `SitemapParser` 支援分塊解析，避免一次性將巨大的 XML 文件載入記憶體。

### 成果
- 500,000 URLs 級別下的峰值記憶體減少了約 **31%**。
- 處理大型 Shard 時的記憶體壓力變得平穩。
