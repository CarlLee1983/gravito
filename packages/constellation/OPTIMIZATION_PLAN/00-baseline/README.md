---

## 目標

建立可量化的性能基準，用於驗證優化效果，並**確認真正的性能瓶頸**

---

## 任務

1. 建立 XML 構建性能基準測試 ✅
2. 建立完整流程端到端基準測試（10K, 50K, 100K, 500K URLs） ✅
3. 建立內存使用監控腳本 ✅
4. **新增**：分析各階段耗時佔比，確認真正瓶頸 ✅
5. 測試增量生成性能（小變更 vs 大變更） ✅

---

## 基準指標

- XML 構建吞吐量（entries/sec）
- 完整 sitemap 生成時間（ms）
- 內存峰值使用（MB）
- 分片生成性能（shards/sec）
- 增量生成性能（變更數 vs 時間）
- **新增**：各階段耗時佔比（%）

---

## 狀態：已完成 (2026-01-19)

基準測試已完成，結果記錄於 `bench/BASELINE.md`。

### 關鍵發現
- XML 構建在 500K 級別下內存使用較高。
- 增量生成在變更比例低於 30% 時具有顯著優勢。
- 內存優化後（Phase 1/3/5）峰值內存減少了約 31%。
