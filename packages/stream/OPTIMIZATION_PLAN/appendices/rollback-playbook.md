# 回滾與切換檢核表

本檢核表用於高風險 Phase 的 Feature Flag 與回滾流程。

## 切換點清單

- [ ] Lua 腳本啟用/關閉
- [ ] Pipeline 啟用/關閉
- [ ] BLPOP 啟用/關閉
- [ ] popMany 啟用/關閉
- [ ] Consumer 批量/並發啟用/關閉
- [ ] Persistence 緩衝啟用/關閉
- [ ] 序列化器切換（JSON/MessagePack）

## 回滾觸發條件

- [ ] 吞吐量下降 > 10%
- [ ] 延遲 P95 上升 > 10%
- [ ] 錯誤率上升 > 1%
- [ ] 資源使用暴增（CPU/記憶體）

## 回滾步驟

1. 關閉相關 Feature Flag
2. 重啟服務（如需要）
3. 驗證基準指標是否恢復
4. 記錄回滾原因與影響

## 回滾後驗證

- [ ] 基本功能正常（push/pop）
- [ ] Group FIFO 正確
- [ ] 監控/告警正常
- [ ] 無額外錯誤
