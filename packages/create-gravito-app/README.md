# create-gravito-app

> Scaffold a new Gravito project in seconds.

## Usage

### With Bun (Recommended)

```bash
bun create gravito-app my-app
```

### With NPM

```bash
npm init gravito-app my-app
```

### With Yarn

```bash
yarn create gravito-app my-app
```

### With PNPM

```bash
pnpm create gravito-app my-app
```
